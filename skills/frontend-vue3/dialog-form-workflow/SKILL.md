# Vue 3 弹窗表单实现

## 前置检查

1. 读取 `AGENTS.md`，确认 `techStack == frontend-vue3`。
2. 阅读同目录已有弹窗或表单实现，优先沿用相邻模式。

## 实现流程

1. 判断是新增弹窗、改造存量弹窗，还是修复弹窗流程。
2. 新增弹窗默认创建 `*Dialog.vue`，与页面同域放置。
3. 父组件只传初始化数据并监听 `saved`；保存、校验、提示和本地表单状态由弹窗内部处理。
4. 打开时拷贝初始化数据到本地 `formData`，关闭时清理脏状态。
5. 保存成功后关闭弹窗并通过 `saved` 通知父组件刷新。

## 回归重点

- 首次打开、编辑回填、二次打开和关闭重置。
- 必填校验、提交中禁用、失败后重试。
- 成功后列表刷新策略是否符合当前页预期。
- 日期、人员、渠道、导入等字段是否使用项目封装组件。

## 输出格式

1. 弹窗职责边界
2. 父子组件交互协议
3. 表单状态与校验策略
4. 保存与刷新策略
5. 回归清单
