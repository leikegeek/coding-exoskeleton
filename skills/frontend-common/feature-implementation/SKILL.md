# 前端功能实现

## 前置检查

1. 读取 `AGENTS.md`，确认 `techStack` 为 `frontend-vue3` 或 `frontend-react-umi`。
2. 若不是前端 profile，跳过本 skill，回退到通用 `coding` / `tech-design`。
3. 若命中 Vue 或 React 专项 profile，再叠加对应 profile skill 与 rules。

## 工作流

1. 阅读入口页面、子组件、状态、API/service、类型、样式和相邻实现。
2. 画出最小实现链路：入口、数据来源、状态变化、提交或刷新路径。
3. 修改前输出：当前理解、方案、涉及文件、风险点、回归点。
4. 按最小范围改代码，优先复用现有组件、工具和目录结构。
5. 收口时说明行为变化、未覆盖风险和建议验证命令。

## 重点检查

- 路由或入口是否可达。
- API 参数、响应字段、空值处理是否一致。
- 表单默认值、校验、提交中、重复提交是否完整。
- 列表分页、筛选、排序、刷新和选中态是否稳定。
- 弹窗关闭后是否清理脏状态并按预期刷新。
- 权限显隐、禁用态和异常提示是否符合现有项目风格。

## 输出格式

1. 当前理解
2. 实现方案
3. 涉及文件
4. 风险点
5. 代码修改摘要
6. 回归测试建议
