# 后端性能分析

## 前置检查

1. 读取 `AGENTS.md`，确认 `techStack` 属于后端 profile（当前内置：`cola-java`）。
2. 不匹配时跳过本 skill，使用 `performance-analysis` 或对应 profile 性能 skill。
3. 明确接口、任务、消息或批处理入口，以及数据规模和 SLA。

## 分析流程

1. 画出调用链：入口 -> 编排 -> 数据访问 -> 外部调用 -> 写入/返回。
2. 识别主要瓶颈：数据库、远程调用、批处理、事务锁、序列化、缓存或线程池。
3. 计算真实操作次数，区分批次数、总数据量、并发度和失败重试成本。
4. 优先建议低风险改法：批量查询、批量写入、分页、缓存、去重请求、异步分批。
5. 每条建议给出验证方式、回滚方式和可能副作用。

## 高风险信号

- 循环内数据库查询、写入、RPC、HTTP 或缓存远程调用。
- 一次性全量加载大表、大文件或大对象集合。
- 长事务包裹远程调用、文件处理或大批量计算。
- 无上限批量接口、无分页消费或无失败补偿。
- 缓存 key 粒度过粗、过细或缺少失效策略。

## 输出格式

1. 入口与调用链
2. 数据规模与证据
3. 性能风险
4. 优化方案
5. 验证与回滚
