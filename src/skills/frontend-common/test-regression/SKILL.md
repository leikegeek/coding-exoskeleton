# 前端回归测试设计

## 前置检查

1. 读取 `AGENTS.md`，确认 `techStack` 为 `frontend-vue3` 或 `frontend-react-umi`。
2. 若不是前端 profile，跳过本 skill，使用通用 `testing`。
3. 明确变更类型：功能、Bug、重构、API、性能或样式。
4. 读取变更文件和任务说明，按影响面确定回归层级。

## 分层策略

- L0 开发自测：页面可进入、核心操作可执行、控制台无新增错误。
- L1 提测冒烟：查询、分页、提交、弹窗、异常提示和权限态主链路。
- L2 上线前关键链路：跨页面状态、慢返回、空数据、失败重试、导入导出或批量操作。

## 必覆盖路径

- 正常路径：主流程成功执行。
- 边界路径：空值、空数组、极端输入、重复点击、切换筛选。
- 异常路径：接口失败、超时、权限不足、提交校验失败。
- 回归路径：相邻页面、共享组件、公共请求栈、路由和全局状态。

## 输出格式

1. 受影响功能点
2. 正常路径
3. 边界路径
4. 异常路径
5. 回归路径
6. 单测建议
7. E2E 建议
8. 未覆盖风险
