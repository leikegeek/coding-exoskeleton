# 前端 API 契约核对

## 前置检查

1. 读取 `AGENTS.md`，确认 `techStack` 为 `frontend-vue3` 或 `frontend-react-umi`。
2. 若不是前端 profile，跳过本 skill，回退到通用 `coding` / `testing`。
3. 优先读取项目已有接口文档、生成代码说明、`docs/*api*` 或变更记录。

## 核对流程

1. 找到 API/service 定义、调用页面、表单模型、展示模型和类型定义。
2. 对比列表、详情、提交、导入导出等相关接口是否混用字段。
3. 标记字段缺失、命名漂移、可空风险、重复转换和错误处理差异。
4. 给出收敛方案：集中映射、补类型、统一默认值、调整请求 helper 或回退到 codegen。
5. 输出验证路径，覆盖成功、失败、空数据和慢返回。

## 必查项

- 请求参数是否与后端约定一致。
- 响应结构是否被错误解包或过度断言。
- 前端展示字段与提交字段是否混在同一个对象里。
- 多组件是否重复维护同一套字段转换。
- 文件上传、下载、批量操作是否保留统一请求栈能力。

## 输出格式

1. 现状与接口范围
2. 契约不一致点
3. 根因判断
4. 收敛方案
5. 涉及文件
6. 回归建议
