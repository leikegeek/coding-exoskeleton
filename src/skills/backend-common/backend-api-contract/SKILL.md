# 后端 API 契约设计

## 前置检查

1. 读取 `AGENTS.md`，确认 `techStack` 属于后端 profile（当前内置：`cola-java`）。
2. 不匹配时跳过本 skill，回退到 `tech-design` 或对应前端 skill。
3. 若项目存在接口文档、OpenAPI、IDL 或既有同域接口，先读取并沿用约定。

## 工作流

1. 明确调用方、接口职责、请求/响应模型、错误语义和兼容边界。
2. 区分新增接口、兼容性修改和破坏性修改；破坏性修改必须给迁移或灰度方案。
3. 核对鉴权、权限、数据隔离、幂等、重复提交、分页、排序、批量规模和超时行为。
4. 明确 DTO 与持久化对象、领域对象、页面展示模型之间的转换边界。
5. 输出联调和回归路径，覆盖成功、失败、空数据、越权、重复请求和大数据量。

## 必查项

- 请求字段是否有必填、默认值、枚举和长度范围。
- 响应字段是否稳定，是否存在可空字段和兼容兜底。
- 错误码或异常是否能被调用方区分和处理。
- 写接口是否具备幂等、防重复提交或唯一约束。
- 批量接口是否有规模上限、分批策略和部分失败语义。

## 输出格式

1. 接口范围
2. 请求/响应契约
3. 权限与幂等
4. 兼容性风险
5. 验证与联调建议
