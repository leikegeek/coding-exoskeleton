# Claude Code 工具调用预算说明

> 本文件是 Claude Code 平台适配说明，不属于跨平台 shared 规则。

Claude Code 运行时可能受到单轮工具调用数量、并发读取数量或子代理启动数量限制。执行 Exoskeleton 流程时，应在不降低治理标准的前提下做分批处理：

- 单轮响应中避免堆叠过多工具调用。
- 并行读取材料时优先控制在少量核心文件内。
- 子代理启动前先完成上下文收窄；需要多个子代理时，默认按组串行。
- 材料过多时按“核心材料 → 契约与规则 → 证据与验证 → 写入或委派”分批执行。
- 不得为了节省工具调用而跳过必读文件、测试证据、接口契约或审计材料。

跨平台通用原则以 `src/rules/shared/context-batching.mdc` 为准；本文件只记录 Claude Code 运行时的执行注意事项。
