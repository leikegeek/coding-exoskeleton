# Exoskeleton Claude Code Entry

本项目使用 Exoskeleton V2 治理流程。

- 项目画像权威文件：`AGENTS.md`
- Claude Code 命令入口：`.claude/commands/`
- Claude Code 子代理入口：`.claude/agents/`
- Claude Code 技能目录：`.claude/skills/`
- Exoskeleton 技能索引：`.claude/exoskeleton-skill-index.md`

执行需求、设计、编码、审计或交付流程前，优先读取 `AGENTS.md` 获取项目技术栈、架构模式、模块结构和团队约束。

`CLAUDE.md` 仅作为 Claude Code 平台导航入口；流程语义、规则内容和技能定义以 Exoskeleton 安装生成的核心资产为准。
